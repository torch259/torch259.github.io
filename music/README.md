# music/ 文件夹说明

这里用来存放你**本地**的音频文件（mp3 / ogg / m4a / wav 等），播放器会通过同源方式加载它们。

## 如何添加一首歌

1. 把音频文件放进这个 `music/` 文件夹，例如 `music/我的歌.mp3`。
2. 打开 `js/config.js`，在 `MUSIC` 数组里加一条：

```js
const MUSIC = [
  { title: "我的歌", artist: "歌手名", cover: "", src: "music/我的歌.mp3" },
  // 更多歌曲……
];
```

- `title`：歌曲名
- `artist`：歌手名
- `cover`：封面图路径（可选，如 `music/cover.jpg`），留空则显示 `♪` 占位
- `src`：音频文件路径（相对项目根目录）

## 为什么是「本地文件」而不是「读电脑文件」

- 浏览器出于安全限制，网页**不能直接读取你电脑上任意位置的文件**（`file://` 路径会被拦截）。
- 但只要把音频文件放进项目里、和网页一起托管（同源），就能稳定播放，无需后端、无跨域问题。
- 所以「本地播放」的正确做法就是：**文件进项目 → 清单里登记路径**。

## 提示

- 文件名建议使用英文/数字，避免中文路径在某些服务器上的兼容问题（中文一般也能用，但英文最稳）。
- 文件体积越大，页面加载越慢，建议单曲控制在 10MB 以内，或用压缩后的 mp3。
