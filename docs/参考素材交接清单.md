# 参考素材交接清单（视频 / 素材 / UI 策略）

> 用途：把你的参考应用演示视频、相关素材、UI 策略交给我时，按本文格式给。
> **原因**：本环境**没有视频解码能力**（无 ffmpeg / cv2 / imageio，也无法联网安装），MP4 我打不开；但 PNG/JPG/WebP 我能真正"看到"并处理。所以视频必须转成**帧 + 文字时序**。
> 关联文档：[`女神异闻录风格改造执行方案.md`](./女神异闻录风格改造执行方案.md)（Phase 1 产出的 `DESIGN_SPEC.md` 就吃这里的信息）

## 一、三种交付方式（按性价比排序）

| 方式 | 给我什么 | 我能得到什么 | 推荐度 |
|---|---|---|---|
| **A. 帧序列**（最佳） | MP4 导出成 PNG 序列，1080p，**每秒 1–2 帧**或只留关键帧 | 版面、配色、层级、状态、间距、光效，全部可量化 | ⭐⭐⭐⭐⭐ |
| **B. 关键帧截图 + 标注** | 手动截 6–12 张（每个界面状态一张），旁边写"这一帧之后发生了什么" | 足够还原 80%，最省事 | ⭐⭐⭐⭐ |
| **C. 直接丢 MP4** | — | ❌ 我完全读不到，只能你自己看 | ⭐ |

> **动效不要靠视频传达**：视频给我"观感"，**时序表给我"参数"**。同样的动效，一张时序表比 30 秒视频对我有用得多（见第四节）。

### 帧导出方法（任选其一，无需装 ffmpeg）

- **VLC**：打开视频 → 按 `Shift+S` 逐帧截图（截图存到「工具→首选项→视频→视频截图目录」）；
- **PotPlayer**：右键 → 视频 → 图像截取 → 连续截图（可设"每 0.5 秒一张"）；
- **剪映 / Pr**：把视频拖进时间线 → 导出为"图片序列 / 静帧"；
- **偷懒法**：直接播放，每隔几秒按 `Win+Shift+S` 截一张，凑 6–12 张关键状态即可。

导出后放进 `refs/video/`（该目录已在 `.gitignore` 中，**不会被提交、不会上线**），命名 `frame-001.png`、`frame-002.png`…

## 四、UI 策略 & 动效时序表（模板）

### 4.1 结构策略（文字回答即可）

1. 这套 UI 的**信息层级**怎么分？（谁是主角、谁是陪衬）
2. **栅格/留白**：满屏还是有边距？内容偏左/偏右/居中？
3. **卡片/面板**形状：切角？斜切？双线框？圆角？（角度大概多少度）
4. **强调色用法**：什么时候用红？红面积占比大概多少（10%？30%？）
5. **字体**：标题和正文分别什么气质（超粗？窄高？等宽数字？）
6. **状态变化**：hover / active / 切换 分别怎么表现？
7. 有哪些**反例**？（你绝对不想要的，比如大圆角、玻璃拟态、柔和渐变）

### 4.2 动效时序表（每段动效一行）

| 元素 | 起始态 | 结束态 | 时长 | 缓动 | 延迟 | 备注 |
|---|---|---|---|---|---|---|
| 视图切换 | 白屏透明 100% | 透明 0% | 120ms | 线性 | 0 | 闪一帧硬切 |
| 卡片入场 | 左移 -40px + 透明 0 | 原位 + 透明 1 | 220ms | ease-out | 60ms/项 递增 | 硬阴影不跟动 |
| 导航 hover | 无底 | 红斜块从左侧展开 | 160ms | ease-out | 0 | 文字变白 |

## 五、来源与版权判定（会直接影响我怎么用它）

| 情况 | 我能做什么 |
|---|---|
| 素材是**你自有**（自拍/自绘/约稿） | 直接用，随便上线上线 |
| 素材是**你 AI 生成**的 | 直接用，可直接上线 |
| 素材是**官方/第三方画面** | 只作**参考分析**：我从中提取策略（配色比例、栅格、时序、交互模式）与**程序化纹理**，然后用 CSS/SVG/自绘产出**等价观感的原创素材**替换。官方素材留在 `refs/`，不进站点、不进 git |
| 那个"应用"是**别人做的** | 学设计策略没问题；**不照抄它的代码/实现**，也不搬运它的美术资产 |

> 一句话：**策略随便学，资产不能搬。** 而 P5 风 90% 的观感来自几何/配色/字体/动效，学策略已经足够做到位。
