# assets/ —— 美术素材目录（P5 风格改造）

> 总方案见 [`docs/女神异闻录风格改造执行方案.md`](../docs/女神异闻录风格改造执行方案.md)。
> **本目录所有素材新增/修改时，必须同步更新 `MANIFEST.md` 对应行。**
> 全小写连字符命名，不用中文文件名；版权红线：禁止直接使用 ATLUS/P5 官方截图、立绘、UI 贴图与商标。

## 目录约定

| 子目录 | 放什么 | 命名 |
|---|---|---|
| `originals/` | 你的原料（个人照片/自绘/约稿原图），不入最终体积 | `原文件名`（保留来源） |
| `bg/` | 大背景 / Hero 主视觉 | `hero-<主题>.webp` |
| `ui/` | UI 装饰位图（尽量改用 SVG/CSS，仅必要位图放这） | `<用途>-<色>.webp\|svg` |
| `textures/` | 噪点 / 网点 / 斜条纹（优先 SVG data-URI 内联） | `<类型>-<色>.svg\|png` |
| `fonts/` | 自托管字体（woff2，OFL 等可商用开源协议） | `display-latin.woff2` 等 |
| `prompts/` | 每张图/每个字体的生成提示词存档（可复现） | `<素材ID>.md` |

> 预留子目录用 `.gitkeep` 占位（本 README 同级已建结构，按需增删）。
